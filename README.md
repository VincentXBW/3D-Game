Installation
To install either download the main exec and map or compile with g++

G++
Download all files into a single folder
REQUIREMENT of raylib.h raymath.h and rlgl.h (these can be found from the raylib github repository and placed alongside main.cpp) and map.txt

Compile with:
g++ main.cpp -o game.exe -lraylib -lopengl32 -lgdi32 -lwinmm -mwindows
