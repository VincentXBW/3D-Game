### **Alpha version 1.0**

**Installation**
To install either download the main exec or compile with g++

_G++_
Download all files into a single folder
REQUIREMENT of raylib.h raymath.h and rlgl.h, aswell as libraylib.a (these can be found from the raylib github repository and placed alongside main.cpp)

Compile with:
`g++ main.cpp -o game.exe -L. -lraylib -lopengl32 -lgdi32 -lwinmm -mwindows`
